# AGENTS.md — rss2html-cf

Cloudflare Worker that converts RSS/Atom feeds into a simple HTML page. **Zero dependencies**, all logic lives in a single file `src/index.js`.

## Core commands

```bash
npm install          # if esbuild/workerd install scripts are blocked, run npm approve-scripts esbuild workerd first, then reinstall
npm run dev          # local dev, default http://localhost:8787 (wrangler dev)
npm run deploy       # deploy (first time needs npx wrangler login)
```

## Architecture

- Single-file worker: `src/index.js` (exports default `fetch` handler), no external deps, no KV/D1
- Request params: `?url=<feed>&limit=<N>`
  - `url` required, only `http(s)://` accepted, otherwise 400
  - `limit` optional, default 10, max 100, invalid values (`abc`/`0`/negative) fall back to default
- Fetch uses `cf: { cacheTtl: 300, cacheEverything: true }` and a custom User-Agent

## Parser (regex-based, no XML library)

- Format detection order: `<feed>` → Atom; `<rss>` / `<rdf:RDF>` → RSS; otherwise 502
- RSS: items inside `<channel>`, fields title/link/pubDate/dc:date/description
- Atom: entries inside `<entry>`, fields title/link(href attribute)/updated/published/summary/content
- Relative links resolved via `new URL(link, base)` (common for Atom href="/posts/1")

## Text cleaning & security (handle with care)

- `cleanText` (titles/dates): decode entities + strip all tags
- `cleanHtml` (descriptions): strip CDATA wrappers, decode entities, remove `<script>`/`<style>`, keep the rest of the HTML
- Entity decode order is fixed: `&amp;` decoded last to avoid double-decoding
- On output, titles are always `escapeHtml`'d; descriptions are pre-cleaned HTML inserted as-is
- Footer shows `X entries · generated by rss2html`

## Error code conventions

| Status | Scenario |
|--------|----------|
| 400 | missing/invalid url param |
| 404 | feed has no entries, non-`/` path |
| 502 | fetch failure, HTTP error, parse failure |

## Testing

No test framework. Smoke test script at `/tmp/opencode/rss2html-test.mjs` (mocks global fetch, 22 assertions), or run dev server locally and verify with curl.

## Three deploy paths (each has its own README section)

1. One-click button (needs GitHub repo)
2. Web Code Editor: paste full `src/index.js` (no git needed)
3. `wrangler deploy`
